# PhysFrame

PhysFrame is a mobile-first React + TypeScript web application for building realistic smartphone image prompts through an Arabic interface.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- IndexedDB for the reference image
- localStorage for scene state and saved presets

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
